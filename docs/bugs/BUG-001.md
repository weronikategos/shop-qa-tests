# BUG-001: The sales report is available to every logged-in customer

| Field | Value |
|---|---|
| Severity | **high** (business data leak) |
| Status | open |
| Environment | flask-sql-shop in Docker, Chromium |
| Test case | TC-M-02 |
| Automated test | `tests/test_known_bugs.py::test_sales_report_is_not_available_to_regular_customer` |

## Steps to reproduce
1. Sign up as a regular customer and log in.
2. Click "Report" in the menu or open `/report`.

## Expected result
A regular customer has no access (redirect or 403). Only an administrator can see the report.

## Actual result
The page returns 200 and shows the whole shop's revenue, revenue by category and the best-selling products. With the demo data, a regular customer (`anna1@example.com`) sees about 89,000 PLN of total revenue.

## Cause (from reading the code)
The `report` view in `shop/routes.py` only has the `@login_required` decorator. The shop has no administrator role.

## Suggested fix
Add an `is_admin` column to the `customers` table and an `admin_required` decorator, and show the "Report" link only to administrators.
